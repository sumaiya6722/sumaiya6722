## 🚀 Featured Projects

### 📚 StudyNook

A full-stack **study-room booking platform** where users can search and explore available rooms, view room details, make bookings, and cancel reservations.

An admin system allows rooms and their features to be added, edited, and deleted.

**Tech:** React • Next.js • Node.js • Express.js • MongoDB • Tailwind CSS

---

### 🎓 LifeCoach

A full-stack **learning platform** supporting both free and premium content.

Users can create lessons, like and save content, report lessons, manage their profiles, and track their own content. Administrators can manage users and moderate lessons.

Includes **Stripe integration for premium access**.

**Tech:** React • Node.js • Express.js • MongoDB • Stripe • Tailwind CSS

---

### 📖 BookShelph

A full-stack **online book-borrowing platform** where users can explore available books, search by title or category, view book details, and request books through the borrowing system.

Users can also manage their own profiles.

**Tech:** React • Node.js • Express.js • MongoDB • Tailwind CSS
